# ComplyScan Samples

This folder contains the package images kept for the v0.8 prototype demonstration.

Use these files directly with the frontend upload control when demonstrating image-based inspection. The images here are also used by the targeted-recovery regression tests so the project has one canonical copy of each verified sample.

Current samples:

- `sample-label.png`
- `maggi-mrp-under-seal.jpeg`
- `maggi-mrp-under-seal-handheld.jpeg`
- `maggi-mrp-under-seal-exif-rotated.jpeg`

Do not add experimental or known-failing package images to this folder for the v0.8 demo baseline.
